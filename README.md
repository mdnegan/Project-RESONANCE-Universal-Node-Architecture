# RESONANCE — Civil Resilience Mesh

**Building a decentralised communications network for communities when conventional infrastructure fails.**

RESONANCE is an open-source project exploring how existing consumer hardware, inexpensive microcontrollers and small Linux devices can be combined to create a distributed emergency communications network.

The objective is simple: allow ordinary households, businesses and community organisations to contribute small, independent network nodes that collectively provide an additional layer of communications resilience.

### The vision

A network that does not depend on a single provider, central server or specific hardware manufacturer.

Using a combination of:

- Wi-Fi for local communications and information sharing.
- LoRa / Meshtastic-compatible hardware for low-bandwidth, long-range messaging.
- ESP32 microcontrollers for inexpensive, accessible network nodes.
- Raspberry Pi and Linux devices for gateways and community services.
- USB-powered devices and power banks for operation during mains power failures.
- Smart-home integrations for local alerts and information distribution.

### Universal hardware participation

RESONANCE aims to support multiple installation methods, allowing people to contribute hardware they already own.

Whether it is an ESP32 development board, a Raspberry Pi, a Linux USB computer or a compatible smart-home installation, the goal is to provide a straightforward route to participation.

### Distributed resilience

The network is designed around:

- No single point of failure.
- Local operation without internet access.
- Distributed communication and message relaying.
- Battery-backed operation.
- Graceful degradation when resources become limited.
- Authenticated official information and clearly identified community messages.
- Open standards and interoperable hardware.

### Community first

RESONANCE is intended as a voluntary community resilience layer, complementing existing emergency services and official communications infrastructure, never replacing them.

### Development status

This project is an evolving research and development concept. Hardware compatibility, communication protocols, security, power management and practical deployment models will be developed and tested progressively.

**One node is small. Thousands of independent nodes can become a resilient system.**
